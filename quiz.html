Quiz Help & Information

About This Quiz

This quiz tests your knowledge of the Zero World, a complex fantasy universe with multiple unique continents, each with its own nations, rulers, heroes, gods, and monsters.

The quiz dynamically generates questions from JSON data files containing:

  • data.json: Information about the world, System, continents, nations, rulers, heroes, monsters, and dungeons
  • Gods/gods.json: Information about pantheons, deities, and divine servants

All questions are generated in real-time based on the actual data, ensuring a unique quiz experience each time.

Question Categories

Continent Questions

Test knowledge about continent themes, SA levels, core mechanics, descriptions

Nation Questions

Capital cities, primary races, SA levels, national characteristics

Ruler Questions

Ruler names, unique skills, skill star ratings, leadership styles

Hero Questions

Hero names, titles, famed deeds, levels, races

God Questions

Pantheon names, supreme gods, high gods, domains, inspirations

Monster Questions

Monster names, classifications, ranks, threat levels, star ratings

System Questions

World name, System mechanics, core stats, gacha system, inviolable rules

Dungeon Questions

Dungeon names, locations, themes, bosses, recommended levels

Race Questions

Racial traits, homelands, characteristics, continental distribution

Scoring System

Your score is calculated based on:

  • Base Points: Easy (10), Medium (25), Hard (50)
  • Time Bonus: +1 point for each second remaining on the timer
  • Perfect Quiz Bonus: +100 points for 100% accuracy
  • Difficulty Recognition: Harder questions give more points

Tips for Success

  • Read questions carefully - some may have multiple correct-sounding answers
  • Use hints strategically when you're unsure (can be toggled in footer)
  • Pay attention to question categories for context clues
  • Manage your time - you have 60 seconds per question
  • Review your answers at the end to learn from mistakes
  • Enable sound for auditory feedback on correct/incorrect answers

Data Sources

This quiz uses real data from the Zero World universe:

  • Continents: Eldoria, Mechanis, Spiritus (from data.json)
  • Nations: Multiple nations per continent with detailed information
  • Monsters: Extensive bestiary with classification system
  • System: Detailed mechanics of the world's governing system
  • Gods: Pantheons and deities for each continent
